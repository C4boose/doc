# Harbor Medical — Astro Website

A responsive, modern doctor's-office website built with Astro.

## Pages
- `/` — Home
- `/about/` — About Us
- `/testimonials/` — Testimonials
- `/reviews/` — Reviews

## Features
- Responsive layout
- Sticky header
- Hamburger navigation on mobile
- Accessible navigation labels and focus-friendly controls
- Lazy-loaded below-the-fold images using `loading="lazy"`
- Optimized hero image using `fetchpriority="high"`
- Modern CSS with no UI framework dependency
- Static Astro output

## Run locally

```bash
npm install
npm run dev
```

Check the project:

```bash
npm run check
npm run build
```

## Notes
The images use remote Unsplash image URLs as stock photography placeholders. Replace them with licensed practice photography before production use. Replace the demo phone number, address, email, testimonials, review statistics, and clinician information with verified practice information.
